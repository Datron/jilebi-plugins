### New Prompts

- `documentation-workflow`: Create or update documentation pages with proper structure and formatting
- `knowledge-base-search-workflow`: Search and synthesize information across Confluence spaces

### Minor Changes

- Initial release with 13 tools for Confluence Cloud (REST API v1)
- Read tools: search, get_page, get_page_children, get_comments, get_labels, search_user, get_spaces, get_page_views
- Write tools: add_label, create_page, update_page, delete_page, add_comment
